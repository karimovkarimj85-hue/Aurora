# Аврора ✨

Личное приложение для iPhone: деньги, бизнес (ZK POS и Gain CRM), копилки, цели (тело, голова, дом), задачи и привычки, плюс встроенный ИИ-помощник на Claude.
Дизайн — по Apple Human Interface Guidelines: системный шрифт и цвета, светлая и тёмная тема, «стеклянная» панель вкладок.

Это **PWA**: сайт, который устанавливается на экран «Домой» и работает как приложение, в том числе без интернета.
Сервер не нужен. Все данные хранятся **только на телефоне**, а приложение бесплатно раздаёт GitHub Pages.

| 🎯 Цели | Тело (вес, % жира, талия, графики), деньги (через копилку), мозг и привычки (выполнение за 7 дней), свои цели; экранное время |

## Как запустить на iPhone

### 1. Адрес приложения


**https://karimovkarimj85-hue.github.io/Aurora/**

Сайт публикуется GitHub Pages из ветки `gh-pages`. Новая версия выходит, когда в эту ветку пушится новый коммит;
через 1–2 минуты она появляется на сайте, а Аврора на телефоне предложит «Обновить».

> На бесплатном тарифе GitHub Pages работает только для **публичных** репозиториев.
> Это безопасно: в коде нет твоих данных, они хранятся только на телефоне.

### 2. Установить на телефон

1. Открой адрес в **Safari** (именно в Safari).
2. Кнопка **«Поделиться»** → **«На экран „Домой“»** → «Добавить».
3. Запусти Аврору с иконки и пройди короткую настройку.

### 3. Подключить ИИ

1. Зарегистрируйся на **platform.claude.com**, пополни баланс (хватит $5).
2. **API Keys → Create Key**, скопируй ключ.
3. В Авроре: ⚙️ Настройки → «ИИ (Claude)» → вставь ключ → «Проверить» → «Сохранить».

По умолчанию стоит Claude Opus 5.5 в режиме «Быстро». Если хочешь тратить меньше, выбери Sonnet 5.5 или Haiku 5.5.
Для Opus и Sonnet включён автоматический запасной вариант: если модель откажется отвечать, запрос сам уйдёт на другую модель.

## Важно знать

- **Резервные копии.** Если удалить Аврору с экрана «Домой», данные удалятся вместе с ней. Раз в неделю делай
  ⚙️ → «Сохранить резервную копию» → «Сохранить в Файлы» → iCloud Drive.
- **Ключ ИИ** хранится только на телефоне и в резервную копию не попадает.
- **Обновления.** Когда выходит новая версия, Аврора покажет «Доступна новая версия → Обновить».

## Ограничения iOS и обходные пути

| Хотелось бы | Почему напрямую нельзя | Что сделано вместо |
|---|---|---|
| Экранное время автоматически | API экранного времени Apple доступен только нативным приложениям | Скриншот «Экранного времени» → Аврора сама распознаёт цифры |
| Читать мессенджеры | iOS не даёт приложениям доступ к переписке | Экспорт чата Telegram (`result.json` или `.txt`) → прикрепи в чате Авроры |
| Напоминания по времени | Для push-уведомлений нужен сервер-отправитель | В планах: события в Календарь iPhone или бесплатный Cloudflare Worker |

## Устройство (для разработки)

Без сборки: чистые ES-модули, открываются как есть.

```
index.html            оболочка приложения
manifest.webmanifest  описание PWA (иконка, название)
sw.js                 service worker — офлайн-кэш (при изменениях увеличивай VERSION)
css/app.css           стили
js/main.js            запуск, вкладки, обработка нажатий
js/db.js              IndexedDB (хранилище на устройстве)
js/store.js           данные и расчёты (балансы, прогресс целей, привычки)
js/forms.js           формы в шторках
js/bizforms.js        формы бизнеса: клиенты, сделки, регулярные платежи
js/icons.js           линейные иконки в стиле SF Symbols
js/ai.js              Claude: системный промпт, инструменты, диалог
js/tips.js            подсказки и советы
js/charts.js          графики на SVG
js/views/*.js         экраны
vendor/               Anthropic SDK (собран в один файл, версия 1.5.0)
```

Локальный запуск: `python3 -m http.server 8000` и открыть http://localhost:8000.
