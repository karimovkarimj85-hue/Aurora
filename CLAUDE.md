# Аврора — правила проекта

- **Дизайн:** всегда применяй навык `apple-design` (`.claude/skills/apple-design/SKILL.md`) при любой работе с интерфейсом:
  отклик на нажатие, пружинные интерруптируемые анимации, материалы, типографика, reduced motion/transparency/contrast.
- **Бренд:** стиль компании Gain Tech (референсы в `brand/gain-tech/`): чёрно-белая гамма, широкий геометрический
  шрифт с округлыми прямоугольными формами, тонкие волновые контуры. Никаких градиентов и эмодзи в интерфейсе —
  только линейные иконки (`js/icons.js`). Цвет — только смысловой (доход/расход, ошибки).
- **Язык интерфейса и комментариев:** русский.
- **Без сборки:** чистые ES-модули; при изменении файлов приложения меняй `VERSION` в `sw.js` и `APP_VERSION` в `js/version.js`,
  новые файлы добавляй в `SHELL`. Приложение обновляется у пользователя само (`js/update.js`), переустановка не нужна.
- **Владелец:** валюта — узбекский сум; карты Tez (•4004), TBC, Ипотека банк; SMS HUMO приходят с номера 13131.
  Коды подтверждения из SMS никогда не сохранять и не пересылать.
- **Публикация:** GitHub Pages из ветки `gh-pages`.
